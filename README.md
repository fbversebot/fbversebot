# FBVerse Bot — Facebook Marketplace Automation for Windows

FBVerse Bot helps Facebook Marketplace sellers reduce repetitive
listing work and organize their daily selling workflow.

Manage bulk listings, scheduling, renewals, and inventory
from a Windows desktop application.

## Features

- Bulk listing workflows with CSV inventory import
- Listing scheduling and publishing queues
- Renew and relist management
- Product, vehicle, and property listing workflows
- Separate browser profiles for account management

## Getting Started

1. Visit the official website to explore the features.
2. Request a demo to check whether FBVerse fits your workflow.
3. Follow the download and setup instructions.
